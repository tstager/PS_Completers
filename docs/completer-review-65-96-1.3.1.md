# Completer review: positions 65–96 at v1.3.1

**Baseline:** `master`, HEAD and tag `v1.3.1` at `04cdd463f999cba23324f6ca18907854fd2f6dc5`. Eight groups reviewed four scripts each and their companion documentation. **Result: 23 medium and 12 low findings** (IDs group related observations). All 32 passed the structural and cold-load checks; all 32 had at least one behavioral or documentation finding. No high-severity outcome was established.

**Fix first:** Remove environment values from printenv tooltips (M1), keep filename suggestions out of password slots (M2), and keep ordinary Tab independent of extension initialization and unvalidated native help arguments (M3–M4). For the broadest correctness gain, test the *accepted line*: a plausible suggestion can erase text right of the cursor, duplicate a filename prefix, or insert syntax instead of one argument (M8–M10). M11's end-of-options defect affects 14 scripts.

## Medium findings

### M1. printenv includes environment values in the completion menu
**R, synthetic environment.** A synthetic variable named `FIXTURE NAME` produced its **value** as the tooltip for `printenv FIX`. A menu can thus reveal sensitive values when the user is only selecting names. Use a fixed description and test that neither display text nor tooltips contain the value. No real environment value was inspected or disclosed. **Lines:** [printenv:132–134](../printenv_completer/printenv_completer.ps1#L132).

### M2. Sensitive slots can replace the intended text
**R for pspasswd; S + isolated span check for pslist/psloglist.** With the account slot filled, a quoted new-password prefix beginning with an at-sign offered a matching fixture filename. The host-file branch precedes the sensitive positional branch. Selecting a result would change the intended argument; no password was set or read. Handle password/terminal slots first, preserve the exact current text, and allow host-file suggestions only in the initial target slot. At the end of a filled form, returning an empty result also allowed filename fallback. Separately, pslist and psloglist derive a no-op password echo from just the prefix left of the caret. Source trace plus an isolated synthetic native-registration check of the same span mechanism showed that replacing `SAM^PLE` with `SAM` truncates the token. Use full span text for sensitive echoes; no real credentials were used. **Lines:** [pspasswd:194–204](../pspasswd_completer/pspasswd_completer.ps1#L194); [pslist:597–600, 370–371, 650](../pslist_completer/pslist_completer.ps1#L597); [psloglist:89–95, 321](../psloglist_completer/psloglist_completer.ps1#L89).

### M3. Cold pi root completion runs extension initialization
**S.** The capture runs `pi --help`; the [companion:87](../pi_completer/pi_completer.md#L87) says that this loads installed extensions. A timeout can limit the wait, but not undo initialization effects. Prefer passive metadata/static completion by default, with explicit refresh outside Tab when extension loading is necessary. No extension startup or side effect was observed in this review. **Lines:** [pi:886, 438–455, 493–503](../pi_completer/pi_completer.ps1#L886).

### M4. Validate the netsh context before starting help discovery
**S + recording stub.** The stub recorded a help request for a context absent from the synthetic root catalog. The callback passes the parsed `-c` value into lazy loading *before* resolving it against known context paths. Appending `/?` and using an argument list does not validate the preceding native arguments. Reject unknown path components before capture; assert that a rejected context makes zero process requests. No native invocation or state change was demonstrated. **Lines:** [netsh:717–718, 1303–1305, 149–165](../netsh_completer/netsh_completer.ps1#L717).

### M5. OpenCode retains whole configuration objects to complete identifiers
**S.** Config loading stores the parsed root in the session cache. That includes fields such as a literal provider API key, although the completion logic needs only a presence bit and selected metadata. Project the fields needed during loading and discard the parsed config; do not conflate this cache with the separate names-only credential-store cache. No actual secrets were read or disclosure observed. **Lines:** [opencode:311–316, 339–346, 477–480, 661–662, 717–724](../opencode_completer/opencode_completer.ps1#L339).

### M6. Local discovery can enumerate a network-backed path
**S.** psgetsid and psinfo use the parent of a typed host-file path directly in provider calls. Neither checks that the resolved root is local before enumeration; psinfo also tests existence first. A UNC prefix can therefore cause filesystem access on Tab, without running PsTools. Reject nonlocal parents *before* any existence or enumeration call and preserve the typed token so the engine does not retry it. No remote lookup or delay was observed. The same unguarded parent lookup occurs in psloglist path slots, psmux paths and its PATH executable scan, and pspasswd's host-file slot. For PATH discovery, exclude network-backed entries before even checking existence. PsExec likewise enumerates host-file parents without a local-only guard. markitdown's documented local path route also tests and enumerates a user-derived DirectoryInfo. Two automatic lookups need the guard even without a network prefix in the current word: Oh My Posh trusts its configured theme root and Ollama trusts its model root. **Lines:** [psgetsid:220–244](../psgetsid_completer/psgetsid_completer.ps1#L244); [psinfo:135–149, 255–256](../psinfo_completer/psinfo_completer.ps1#L139); [psloglist:186–204](../psloglist_completer/psloglist_completer.ps1#L186); [psmux:480–490, 680–685](../psmux_completer/psmux_completer.ps1#L480); [pspasswd:99–113](../pspasswd_completer/pspasswd_completer.ps1#L99); [psexec:232–239, 278–291](../psexec_completer/psexec_completer.ps1#L232); [markitdown:343–363](../markitdown_completer/markitdown_completer.ps1#L343); [OhMyPosh:215–217](../OhMyPosh_completer/OhMyPosh_completer.ps1#L215); [ollama:716–721, 728–735](../ollama_completer/ollama_completer.ps1#L716).

### M7. Later tokens change the active completion slot
**R, fixtures.** `nl.exe --number-format r^ later` offered a fixture filename instead of `rn`/`rz`; `pr --width 7^ note.txt` gave file `7file` rather than `72`. mktemp lost its directory-only `-p` result with a later template, nproc lost its numeric `--ignore` hint, od lost its `-A` radix, and paste treated a delimiter as a file. End-of-line controls stayed in their value slots. In `psfile -^ 123`, the later identifier enabled `-c` *before* the identifier. Determine the predecessor and settled arguments from extents before the active word, not the tail of the entire AST. **Lines:** [nl:213–220, 357–364](../nl_completer/nl_completer.ps1#L213); [nproc:146–159, 196–202, 253–264](../nproc_completer/nproc_completer.ps1#L196); [psfile:60–64](../psfile_completer/psfile_completer.ps1#L60); [od:153–166, 264–270](../od_completer/od_completer.ps1#L264); [paste:223–231, 304–307](../paste_completer/paste_completer.ps1#L223); [pr:160–173, 279–286](../pr_completer/pr_completer.ps1#L279); [mktemp:246–252, 341–342](../mktemp_completer/mktemp_completer.ps1#L246).

### M8. Mid-token matching and replacement need different spans
**R.** `npm.exe vers^zzz`, `oh-my-posh --shell=p^zz`, `pathchk --v^zzz`, `psmux sele^ZZZZ`, and Playwright CLI's browser prefix `fir^zz` all lost candidates matching the prefix before the caret. Conversely psgetsid offered `Sample` to replace all of `Sample^Identity`. For `printf 'cost: %^ USD'`, accepting `%d` removed ` USD`. Filter on the prefix, preserve the whole word for no-op results, and splice format conversions without dropping unrelated suffix text. **Lines:** [npm:1427–1429](../npm_completer/npm_completer.ps1#L1427); [psgetsid:489–491, 210–211, 552–560](../psgetsid_completer/psgetsid_completer.ps1#L489); [OhMyPosh:194–197](../OhMyPosh_completer/OhMyPosh_completer.ps1#L194); [pathchk:124–125, 141–145](../pathchk_completer/pathchk_completer.ps1#L141); [psmux:821–836](../psmux_completer/psmux_completer.ps1#L821); [printf:349, 373–376, 412–419](../printf_completer/printf_completer.ps1#L373); [playwright_cli:950–957, 1044–1045](../playwright_cli_completer/playwright_cli_completer.ps1#L950).

### M9. md5sum duplicates the prefix of a comma-containing filename
**R, fixture file.** For `md5sum comma,n`, PowerShell replaced only the last character (index 13, length 1). Returning the whole quoted fixture name produced `md5sum comma,'comma,name.txt'`, not the selected filename. The already-quoted control worked. Respect the engine's replacement span; if a full-operand replacement is impossible, do not emit a misleading candidate. **Lines:** [md5sum:133–141, 177–181, 205–221](../md5sum_completer/md5sum_completer.ps1#L133).

### M10. Render each selected value as one literal argument
**R, fixtures.** The npm script `build docs`, variable `FIXTURE NAME`, spaced process names in ProcDump and pskill, and psmux command `Alpha App.exe` were inserted bare, splitting the selected name in two. numfmt's semicolon and pipe delimiters parsed as syntax; psmux's `#S` format parsed as a comment. Playwright CLI's unquoted JavaScript template `() => { }` did not parse as one literal argument either. ProcDump also returned a spaced counter example verbatim. Render each insertion as one PowerShell literal whether or not a quote is already open. Keep the raw display label; check the accepted AST without running the target. **Lines:** [npm:1268–1273, 1396–1401](../npm_completer/npm_completer.ps1#L1268); [numfmt:208–209, 262–271](../numfmt_completer/numfmt_completer.ps1#L208); [printenv:120–134](../printenv_completer/printenv_completer.ps1#L134); [pskill:103–105, 319–325](../pskill_completer/pskill_completer.ps1#L103); [psmux:245–250, 716, 759, 783](../psmux_completer/psmux_completer.ps1#L759); [procdump:253, 284, 561, 568](../procdump_completer/procdump_completer.ps1#L561); [playwright_cli:652–658, 841–846](../playwright_cli_completer/playwright_cli_completer.ps1#L841).

### M11. A committed option delimiter does not end option dispatch
**R, cached or stubbed catalogs.** After a committed `--`, markitdown/md5sum offered `--help` for filenames; nl, nproc, numfmt, paste, pathchk, pip and pr likewise returned tool switches in operand slots. printf offered `--help` as a format and `--version` even after a format. OpenCode offered run options in its positional tail. npm and pnpm offered their own options in forwarded script arguments; pi rewrote message text `--mode=j` to `--mode=json`. Track the terminator before both attached-value and option-name dispatch. Use only valid operand completion thereafter, or preserve forwarded text. **Lines:** [nl:357–371](../nl_completer/nl_completer.ps1#L357); [npm:1457–1467, 1509](../npm_completer/npm_completer.ps1#L1457); [nproc:253–273](../nproc_completer/nproc_completer.ps1#L253); [numfmt:331–356](../numfmt_completer/numfmt_completer.ps1#L331); [pi:2181–2183, 2305–2314, 2333](../pi_completer/pi_completer.ps1#L2305); [pnpm:407–417, 842–851](../pnpm_completer/pnpm_completer.ps1#L407); [opencode:968–983, 1142–1144](../opencode_completer/opencode_completer.ps1#L968); [paste:313–322](../paste_completer/paste_completer.ps1#L313); [pathchk:237–245](../pathchk_completer/pathchk_completer.ps1#L237); [pip:610–618, 681–683](../pip_completer/pip_completer.ps1#L610); [printf:465–475](../printf_completer/printf_completer.ps1#L465); [pr:441–451](../pr_completer/pr_completer.ps1#L441); [markitdown:601–625](../markitdown_completer/markitdown_completer.ps1#L601); [md5sum:205–221](../md5sum_completer/md5sum_completer.ps1#L205).
